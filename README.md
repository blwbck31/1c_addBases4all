Разовое подключение базы 1С для всех пользователей сервера

Данный способ подходит в случае, если необходимо однократно подключить информационную базу 1С всем пользователям сервера.

Где хранится список информационных баз

Список информационных баз конкретного пользователя хранится в файле:

C:\Users\<имя_пользователя>\AppData\Roaming\1C\1CEStart\ibases.v8i

Формат записи информационной базы

В файл ibases.v8i необходимо добавить запись следующего вида:

[<Название базы>]
Connect=Srvr="<имя_или_ip_сервера>";Ref="<имя_базы>";
ClientConnectionSpeed=Normal
App=Auto
WA=1
Version=<8.2 или 8.3>


Остальные параметры добавляются автоматически при первом запуске 1С.

Массовое добавление базы для всех пользователей

Для удобства рекомендуется:

Создать файл Base.txt, содержащий готовую запись информационной базы.

Использовать PowerShell-скрипт для добавления этой записи в файлы всех пользователей.

Например:

Base.txt — содержит описание базы

add.ps1 — PowerShell-скрипт, который добавляет данные из Base.txt во все файлы ibases.v8i пользователей

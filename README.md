# Массовое подключение базы 1С для всех пользователей сервера

Инструкция описывает разовое подключение информационной базы **1С** всем пользователям сервера Windows.

## Когда использовать

Данный способ подходит, если требуется **однократно** подключить одну и ту же информационную базу 1С:

* всем существующим пользователям сервера;
* без ручного входа под каждым пользователем.

---

## Где хранится список информационных баз

У каждого пользователя список информационных баз хранится в файле:

```text
C:\Users\<имя_пользователя>\AppData\Roaming\1C\1CEStart\ibases.v8i
```

Файл `ibases.v8i` — обычный текстовый файл.

---

## Формат записи информационной базы

Для подключения новой базы в `ibases.v8i` необходимо добавить запись следующего вида:

```ini
[<Название базы>]
Connect=Srvr="<имя_или_ip_сервера>";Ref="<имя_базы>";
ClientConnectionSpeed=Normal
App=Auto
WA=1
Version=<8.2 или 8.3>
```

> Остальные параметры будут добавлены автоматически при первом запуске 1С пользователем.

---

## Массовое добавление базы

Для автоматизации рекомендуется:

1. Вынести описание базы в отдельный файл.
2. Использовать PowerShell-скрипт для модификации `ibases.v8i` всех пользователей.

---

## Рекомендуемая структура файлов

```text
/
├── Base.txt        # описание информационной базы
├── add.ps1         # PowerShell-скрипт
```

### Base.txt

Содержит готовую запись информационной базы в формате `ibases.v8i`.

### add.ps1

PowerShell-скрипт:

* перебирает профили пользователей;
* находит файл `ibases.v8i`;
* добавляет содержимое `Base.txt` (если база ещё не добавлена).

---

## Примечания

* Скрипт необходимо запускать с правами администратора.
* Рекомендуется сделать резервную копию `ibases.v8i` перед массовыми изменениями.
* Метод рассчитан на **разовое** добавление базы, а не на постоянную синхронизацию.
